Figures¶

Every figure on this site is drawn by a Python module from facts extracted from the code, so it is rebuilt, not redrawn, when the code changes. CI runs kokeb-docs figures --check and fails when a committed figure no longer matches the code. Each figure below lists the files it is drawn from.

ASCII poll of the data frame¶

Figure description and sources

The TX lane is what the host sends and the RX lane what the instrument answers, left to right in time. On TX the unit ID A and a carriage return poll the whole data frame; after the idle timeout the instrument sends on RX its unit ID, the temperature, flow and the other fields (some are left out) and the gas, then a carriage return. The table gives the idle timeout in byte times.

The layers, one of them yours¶

Figure description and sources

Top to bottom, each arrow is a call. Your application calls one object, whose public calls are listed from the umbrella header in inc/. The core turns each call into register reads and writes and hands them to the port contract (the CRTP base in inc/*_interface.hpp), which forwards them, at compile time, to the hooks of the port class you write; your port moves the bytes on the bus. The notes on the right say which layers stay the same on every MCU and which one you write. A library without a port contract has only the first two layers.

One call through the layers¶

Figure description and sources

Participants, left to right: Your code, Basis2, Bus and Your port. The steps run from top to bottom. Your code sends ReadFlow() to Basis2. Basis2 does ascii::Make(Poll) builds and checks the bytes itself. Basis2 sends Execute(request, timing) to Bus. A note over Bus says: wait t3.5 of silence. Bus sends FlushInput(), Write("A\r") to Your port. A note over Bus and Your port says: Repeat until a CR or the deadline. Bus sends Read(buffer) to Your port. A note over Bus and Your port says: End of the repeated steps. Your port returns "A +012.30 +024.8 ... Air\r" to Bus. Bus returns Reply to Basis2. A note over Basis2 says: strict grammar, unit ID, range. Basis2 returns Result of Decimal to Your code.

Several BASIS 2 on one RS-485 line¶

Figure description and sources

The MCU on top and the BASIS 2 instruments under it connect to the rails B (+) and A (-) on the right, on pins 5 and 6 of each connector; the dashed card stands for the instruments in between. Each instrument needs a unique unit ID, A to Z, for ASCII and a unique Modbus address, 1 to 247, for Modbus RTU.

UART character¶

Figure description and sources

The lane is TX, left to right in time, and the RX line carries the same format in the other direction. The line idles high, the start bit pulls it low for one bit time, the data bits D0 to D7 follow and the stop bit returns it high. The table gives the default bit rate and the range of rates the instrument can be set to.
