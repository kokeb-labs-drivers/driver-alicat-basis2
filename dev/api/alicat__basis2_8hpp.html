Detailed Description

ALICAT_BASIS2 driver: the one header to include.

Copyright (c) 2026 The driver-alicat-basis2 authors. SPDX-License-Identifier: MIT

alicat_basis2::Basis2<Port> drives one Alicat BASIS 2 mass flow meter (B series) or controller (BC series) through a Bus<Port> that owns the serial port. The driver speaks the instrument's ASCII protocol ("BASIS Protocol 2", the default) or Modbus RTU behind the same typed API. It has no platform code, allocates nothing, throws nothing, takes no lock and is not thread-safe: give each bus one owner, or guard it with one mutex.

Streaming mode is never started; broadcast (*) is never sent; there is no raw-text call. Six commands can strand the instrument (unit ID, Modbus address, baud rate, protocol switch, factory restore) and need a guard token naming the consequence.

Not verified on hardware: every reply format the manual does not show is an assumption with a knob (see docs/configuration.md).
