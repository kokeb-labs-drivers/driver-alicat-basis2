Detailed Description

template<UartPort Port>
class alicat_basis2::Bus< Port >

The transaction machine of one serial line, shared by every instrument on it.

One transaction at a time ("behavior undefined" otherwise, M p.10): Submit() on a busy bus returns Busy and sends nothing. After a timeout, an overflow, a bad line or a wrong-ID reply the bus waits out the failed request's reply wait and drains the line until it has been quiet for t3.5 + 2 ms before it sends again, so a late reply is never taken for the next answer. A request that never reached the wire (the line did not go quiet) only needs the quiet line. While idle, bytes that arrive are counted as stray lines and never used.
