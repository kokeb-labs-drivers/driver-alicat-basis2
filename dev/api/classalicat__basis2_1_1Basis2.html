Detailed Description

template<UartPort Port>
class alicat_basis2::Basis2< Port >

Driver for one instrument on a Bus.

Lifecycle: construct with the configuration (no I/O), then EnsureInitialized() (port up, configuration checked), then Begin() (a read-only sequence that learns the identity). Every call that touches the instrument returns NotInitialized before EnsureInitialized() has succeeded.

Learn the instrument: a poll, the firmware, serial number, full scale, gas, totalizer limit, averaging, reference temperature and, for a controller, setpoint source, ramp and autotare. Sends no write.

The instrument needs about one minute after power-up to settle (S19 p.1). In Modbus mode Config::modbus_flow_decimals must be set (A11).

Returns
Ok, NotInitialized, InvalidArgument (Modbus decimals unset), or the error of the first failing transaction.

◆ Recover()

template<UartPort Port>
Result< void > alicat_basis2::Basis2< Port >::Recover ( )
noexcept

Find the instrument again after a guarded command left StateUnknown or after a lost line: poll the configured ID, else (only when Bus::DeviceCount() is one) scan A to Z or the Modbus addresses, adopt the ID that answers and run Begin(). StateUnknown ends only when that Begin() succeeds and the serial number, firmware and kind equal those learned before; on any failure the driver stays in StateUnknown and keeps its old ID.

Returns
Ok, NotInitialized, Timeout (nothing answered), VerifyMismatch (another instrument answered) or an error of Begin().
