Detailed Description

template<typename Derived>
class alicat_basis2::UartInterface< Derived >

CRTP base of the platform serial port.

Derive class MyPort : public alicat_basis2::UartInterface<MyPort> and implement the hooks above. The base declares no hook and no data; the driver checks your class with the UartPort concept.
