Detailed Description

Request and Reply: the only things the driver puts on and takes off the wire, and the timing formulas that size every wait.

A Request can be made only by the factories of alicat_basis2_ascii.hpp and alicat_basis2_modbus.hpp, which validate every argument; its constructor from data is private. There is no way to send raw text.
