const FrameRules &  rules,
Frame &  out 
)
inlinenoexcept

Decode a DV n reply: ID, then the selected fields in table order (M p.11).

Each numeric bit takes one token, the gas one token, and the status the rest: flag tokens, or one unsigned integer equal to the Modbus register 2101 bits (A4).

Parameters
lineThe reply line.
maskThe requested bits, 1 to 255.
rulesThe addressed ID and limits.
outThe frame with present == mask; untouched on failure.
Returns
Ok, DeviceIdMismatch, BadReply or OutOfRange.

◆ IsLegalRequest()

bool alicat_basis2::ascii::IsLegalRequest ( std::span< const uint8_t >  bytes)
inlinenoexcept

Whether bytes is exactly one request of the grammar of M pp.10 to 17: unit ID A to Z, a command with its argument, one CR at the end, only the characters A-Z 0-9 space + - . * @ =.

Hand-written and independent of kCommands: a mismatch between the table and this function is a build failure of tests/test_grammar.cpp. The driver runs it before every Write().

Parameters
bytesThe candidate wire bytes.
Returns
true when it is a legal request.

Build a request: validate every argument, write the wire bytes.

Guarded rows are built only when allow_guarded is true; the public guarded calls of Basis2 pass it after checking their token. A rejected argument returns InvalidArgument and nothing is formed.

Parameters
commandAn ASCII command.
idThe unit ID, A to Z.
argsThe arguments.
allow_guardedWhether a guarded row may be built.
Returns
The request, or InvalidArgument (also for Command::Modbus).
