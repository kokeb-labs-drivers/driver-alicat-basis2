◆ Error

enum class alicat_basis2::Error : uint8_t
strong

Why a call failed. Every call of the driver returns one of these in its Result.

Values 0 to 9 are the shared base set; chip-specific values start at 16. [[nodiscard]] on the type: a function that returns a bare Error cannot have it ignored either (KB-CPP20-037).

Enumerator
Ok 

The call succeeded.

NotInitialized 

EnsureInitialized() failed, or Begin() has not run where the call needs it.

InvalidArgument 

An argument or a Config field is out of range; nothing was sent.

Bus 

Write() returned false; nothing is pending afterwards.

Timeout 

No complete reply line (or frame) within the computed time.

DeviceIdMismatch 

The reply carried another unit ID or Modbus address than the one addressed.

Crc 

Modbus CRC-16 mismatch; the whole frame is discarded.

Busy 

The bus was not free (a transaction, quarantine or hold-off), or the line never went quiet: the transaction that met it was not sent (see docs/api-guide.md).

DeviceFault 

Reserved for the instrument's own fault reports.

Unsupported 

The feature is absent in this mode, on this kind of instrument, or on this port.

BadReply 

The line does not match the command's reply grammar.

Rejected 

The instrument answered with the error token ? or a Modbus exception reply.

OutOfRange 

A decoded value is outside what the instrument can physically report.

Overflow 

The reply exceeded the line buffer without a terminator.

VerifyMismatch 

The read-back after a setter differs from what was written.

FirmwareTooOld 

The call needs a newer firmware than the identity says.

StateUnknown 

A guarded command may have changed the line settings and was not confirmed.

RateLimited 

A saved-source setpoint change came sooner than the non-volatile memory allows.

GuardNotConfirmed 

A guarded call was made with a confirmation token of the wrong kind.
