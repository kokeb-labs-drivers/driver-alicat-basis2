Detailed Description

The ASCII grammar of "BASIS Protocol 2" (M pp.10 to 17): the command table, the encoder, the independent wire validator and the pure reply decoders.

Wire form of a request: <ID><TOKEN>[ <ARG>]<CR>. Numbers are formatted in integer arithmetic (never printf("%f"), never an exponent). Everything here is pure: no I/O, no allocation.
