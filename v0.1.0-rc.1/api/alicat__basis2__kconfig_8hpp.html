Detailed Description

Optional ESP-IDF layer: a Config built from the CONFIG_ALICAT_BASIS2_* Kconfig options.

Copyright
Copyright (c) 2026 The driver-alicat-basis2 authors. SPDX-License-Identifier: MIT

Include this header only where you want menuconfig to choose the defaults; the driver never includes it and no driver signature depends on it. Under ESP-IDF the values come from sdkconfig.h. Without Kconfig every option falls back to the datasheet default, so KconfigDefaults() equals Config{}.

Kconfig writes a bool option set to "n" as an absent macro, so an absent CONFIG_ALICAT_BASIS2_MODBUS means ASCII in both cases.

One configuration per program: the inline function below depends on the CONFIG_ macros, so every translation unit of one program must see the same values (ESP-IDF has one sdkconfig.h per build; each host test is its own program). No driver or library header includes this one (handbook KB-CPP20-018).
