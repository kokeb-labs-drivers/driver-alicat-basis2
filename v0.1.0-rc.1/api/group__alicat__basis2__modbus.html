inlinenoexcept

Whether bytes is exactly one request the driver may send: a valid CRC, an address 1 to 247, function 3 on readable registers, function 6 or 16 on writable registers with a legal value.

Independent of the builders: it parses the bytes back and checks them against the register table.

Parameters
bytesThe candidate wire bytes.
Returns
true when legal.
